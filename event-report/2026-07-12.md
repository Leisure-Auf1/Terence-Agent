### 11:15 — 🛡️ GRUB 双引导加固

**描述**: 配置 GRUB 确保 Arch + Windows 双系统在更新后不丢失。

**结果**: ✅ 完成

**操作摘要**:
1. 设置 `GRUB_DEFAULT=saved` + `GRUB_SAVEDEFAULT=true` — 记住上次选择的系统
2. 在 `/etc/grub.d/40_custom` 添加硬编码 Windows 11 启动项 — 不受 os-prober 影响

4. 创建 systemd 服务 `fix-boot-order.service` + 脚本 `/usr/local/bin/fix-boot-order.sh` — 每次开机确保 GRUB 在 UEFI 启动顺序排第一
5. 重新安装 GRUB 到 EFI (`grub-install`)
6. GRUB 菜单现有: Arch Linux / Windows 11 (硬编码) / Windows Boot Manager (os-prober) / UEFI Firmware Settings

### 13:00 — 🔧 桌面崩溃修复 (quickshell SIGSEGV)

**描述**: 系统更新后 quickshell 因 QML 缓存不兼容崩溃，导致黑屏。

**结果**: ✅ 完成 — 桌面已恢复

**原因**: KDE/Qt6 更新后，旧的 QML 字节码缓存 (.qmlc) 与新库版本不兼容，quickshell 启动时 SIGSEGV。

**修复**:
1. 清除 `~/.cache/quickshell/qmlcache/` 和 `qtpipelinecache/` — 强制重新编译 QML
2. 重启 DMS (dms v1.5.0) — 成功启动
3. 安装 pacman 钩子 `/etc/pacman.d/hooks/clean-qml-cache.hook` — Qt6/KDE 更新时自动清理 QML 缓存，防止复发
